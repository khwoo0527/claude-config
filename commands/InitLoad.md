세션 컨텍스트 로딩 상태를 점검하는 보조 커맨드. (구 버전의 "메모리 수동 일괄 로딩" 역할은 폐기됨)

> **왜 축소되었나**: Claude Code 가 `.claude/rules/` 를 네이티브 자동 로딩하면서 (`paths` 없음 = 매 세션, `paths` 있음 = 매칭 파일 작업 시),
> `.claude/rules/memory/` 의 사용자 메모리와 `rules/workflow/session-init.md` 가 **수동 호출 없이 자동 주입**된다.
> 이 커맨드는 "자동 로딩이 제대로 됐는지 의심될 때" 확인용으로만 남는다. (2026-07-03 개편)

## 인수

`$ARGUMENTS`: 사용하지 않음 (인수 없이 호출 — `/InitLoad`).

## 실행 절차

1. **메모리 로딩 확인**: `.claude/rules/memory/*.md` 글롭 결과와 현재 컨텍스트에 주입된 메모리 내용을 대조한다.
   - 누락 파일이 있으면 해당 파일을 명시적으로 Read 하여 보완한다.
2. **세션 절차 확인**: `rules/workflow/session-init.md` 가 컨텍스트에 있는지 확인, 없으면 Read.
3. **압축 요약 1줄 보고**:
   ```
   ✅ 컨텍스트: {user 핵심} / {feedback 각 핵심 슬래시 구분} / 세션 절차 OK {(보완 N건 — 있을 때만)}
   ```

## 동작 원칙

- 평상시에는 호출 불필요 — 자동 로딩이 기본. 자동 주입이 안 된 것으로 의심되는 예외 상황(구버전 Claude Code, 손상된 설정 등)에서만 사용.
- 로딩 정책의 단일 진실 원천은 [`rules/memory/MEMORY.md`](../rules/memory/MEMORY.md) 의 "로딩 방식" 섹션 — 이 커맨드는 그 정책의 검증만 담당.
